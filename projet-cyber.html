TP Sécurité Web – MySQL

BTS SIO SLAM | Cybersécurité

Présentation

Ce TP a pour objectif d’identifier et corriger des vulnérabilités courantes dans une application web utilisant PHP et MySQL.

Exercice 1 – Injection SQL

Connexion test avec : alice / alice123

  • Payload utilisé : ' OR '1'='1 --

Explication

La requête SQL est construite par concaténation de chaînes, ce qui permet à un attaquant d’injecter du code SQL. La condition '1'='1' est toujours vraie, ce qui permet de contourner l’authentification.

Correction

Utilisation de requêtes préparées avec PDO pour éviter toute injection SQL. 

$stmt = $pdo->prepare("SELECT * FROM users WHERE username = ? AND password = ?");
$stmt->execute([$username, $password]);

Exercice 2 – XSS stockée

  • Payload : <script>alert('XSS');</script>

Observation

Le script est exécuté au rechargement de la page, ce qui montre une faille XSS stockée.

Correction

  • Utilisation de htmlspecialchars()
  • Validation des entrées (whitelist)
  • Ajout possible d’une politique CSP
echo htmlspecialchars($comment, ENT_QUOTES, 'UTF-8');

Exercice 3 – Authentification sécurisée

Améliorations

  • Utilisation de password_hash()
  • Vérification avec password_verify()
  • Requêtes préparées
if (password_verify($password, $hash)) {
    echo "Connexion réussie";
}

Résultat

L’injection SQL ne fonctionne plus car les entrées utilisateur ne sont plus interprétées comme du code SQL.

Technologies utilisées

  • PHP
  • MySQL
  • phpMyAdmin
